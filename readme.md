# Quiz Game Application

A **web-based Quiz Game** that lets users test their knowledge across various topics. The game supports **single-choice**, **multiple-choice**, and **fill-in-the-blank** questions, with real-time progress tracking and a final review of answers.

---

## 🌟 Features

- **Multiple Question Types:** Single-select, Multi-select, Fill-in-the-blank  
- **Progress Tracking:** Real-time progress bar  
- **Navigation:** Next and Back buttons  
- **Input Validation:** Ensures user selects or types an answer  
- **Final Score & Review:** Displays correct/incorrect answers  
- **Responsive Design:** Works across devices  
- **Visual Effects:** Animated color drift and floating orbs
